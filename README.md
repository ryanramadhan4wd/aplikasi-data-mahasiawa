# Aplikasi Data Mahasiswa

Contoh aplikasi web sederhana untuk tugas GitHub.

## Fitur
- Menambahkan data mahasiswa (NIM, nama, program studi)
- Menampilkan data dalam tabel
- Menghapus data mahasiswa
- Validasi NIM agar tidak duplikat selama halaman dibuka

## Teknologi
- HTML
- CSS
- JavaScript

## Cara menjalankan
1. Unduh atau clone repository ini.
2. Buka file `index.html` menggunakan browser.
3. Isi formulir lalu klik **Tambah**.

Catatan: data hanya disimpan sementara selama halaman terbuka. Data akan hilang jika halaman dimuat ulang.
